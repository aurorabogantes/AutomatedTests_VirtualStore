# AutomatedTestsProyecto

Automated test suite for a virtual store web application using Selenium WebDriver and NUnit.

## Description
This project contains automated tests that verify the functionality of a virtual store web application, including:
- Navigation testing
- Contact form submission
- Product creation and validation
- Form validation
- Multi-user simulation

## Prerequisites
- .NET Core
- Chrome browser
- ChromeDriver
- Web application running on https://localhost:7195/

## Test Coverage
The test suite includes verification of:
- Basic navigation and link functionality
- Contact form submission and validation
- Product creation with validation
- Form field validations
- Success message verification
- Multi-user concurrent access simulation

## Test Cases
1. Navigation Testing
2. Contact Form Submission
3. Product Creation
4. Empty Form Validation
5. Navigation Links
6. Contact Success Messages
7. Description Length Validation
8. Empty Product Validation
9. Negative Price Validation
10. Concurrent User Access Testing
